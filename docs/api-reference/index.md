# API Reference

The API reference is generated by Zensical through `mkdocstrings`.

- [Runtime API](runtime-api.md): isolates, contexts, scopes, scripts, modules,
  profiles, snapshots, inspector sessions, and diagnostics.
- [Host APIs](host-apis.md): installable host-side APIs such as timers,
  module loading, console, WebAssembly, Atomics, and ShadowRealm.
- [JS Object](js-object.md): JavaScript values and object wrappers such as
  strings, arrays, promises, typed arrays, maps, sets, and proxies.
